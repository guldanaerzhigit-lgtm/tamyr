# TAMYR

**Тамырыңды таны. Тарихыңды сақта.**

TAMYR — Қазақстан отбасыларына арналған цифрлық шежіре платформасы.

## Қазіргі нұсқа: v0.1

Бірінші интерфейс прототипінде:
- Қазақ тіліндегі адаптивті кабинет
- Интерактивті шежіре ағашы
- Отбасы мүшелерінің карточкалары
- Жаңа адам қосу формасы
- Демо деректерді браузердің localStorage қоймасында сақтау

> Қазіргі деректер демо режимінде браузерде ғана сақталады. Firebase және Cloudflare R2 интеграциясы келесі кезеңде қосылады. Демо адамдардың есімдері тек үлгі ретінде берілген.

## Жергілікті іске қосу

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Келесі кезеңдер

1. Firebase Authentication
2. Firestore деректер моделі және қауіпсіздік ережелері
3. Отбасылық рөлдер мен шақырулар
4. Cloudflare R2 файл қоймасы
5. Шежірені экспорттау және жариялау баптаулары

## Құпиялылық қағидасы

Тірі адамдардың жеке деректері әдепкіде жарияланбайды. Ортақ шежірелерді байланыстыру тек қатысушылардың келісімімен орындалуы керек.
