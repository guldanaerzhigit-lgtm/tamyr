# TAMYR

**Тамырыңды таны. Тарихыңды сақта.**

TAMYR — Қазақстан отбасыларына арналған цифрлық шежіре платформасы.

## Қазіргі нұсқа

- Қазақ тіліндегі адаптивті кабинет
- Firebase Authentication: электрондық пошта және құпиясөз арқылы тіркелу/кіру
- Firestore: әр пайдаланушының жеке әулеті мен адамдары
- Интерактивті шежіре ағашы
- Жаңа адам қосу және Firestore-да сақтау
- Жеке деректерге арналған бастапқы қауіпсіздік ережелері (`firestore.rules`)

## Орнату және іске қосу

```bash
npm install
npm run dev
```

## Firebase баптауы

1. Firebase Console → Authentication → Sign-in method ішінде **Email/Password** әдісін қосыңыз.
2. Firestore Database іске қосылғанына көз жеткізіңіз.
3. Firebase Console → Firestore Database → Rules ішіне репозиторийдегі `firestore.rules` мазмұнын жариялаңыз.
4. Firebase Web config `src/lib/firebase.js` ішінде орналасқан.

## Деректер құрылымы

- `families/{uid}` — пайдаланушының жеке әулеті.
- `families/{uid}/people/{personId}` — әулет мүшелері.

Қазіргі ереже бойынша тек жүйеге кірген иесі ғана өз әулетін оқи/өзгерте алады. Ортақ шежіре, шақырулар және рөлдер кейін бөлек қауіпсіздік моделін қажет етеді.

## Құпиялылық

Тірі адамдардың жеке деректері әдепкіде жарияланбайды. Шежірені жариялау немесе басқа адамдармен бөлісу тек нақты келісім мен арнайы рұқсаттар енгізілгеннен кейін қосылуы керек.
